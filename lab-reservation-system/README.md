# 实验室预约管理系统

一个极简的实验室预约管理系统：**纯静态网页，零依赖、零安装、无需数据库**，双击 `index.html` 即可运行，也可直接部署到 GitHub Pages 在线使用。

## 功能

| 角色 | 功能 |
| --- | --- |
| 普通用户 | 提交预约；查询预约记录（关键词搜索 + 实验室/日期筛选）；预约通过后获取**6 位验证码**，在预约时段内凭验证码**线上签到**；取消自己的预约 |
| 管理员 | 登录后台（默认密码 `admin123`）审核申请；通过后系统自动生成预约验证码；查看**爽约记录**与**受限用户**，可一键**解除限制** |
| 系统 | **冲突检测**：同一实验室+日期+时段被占用时禁止重复预约；**爽约管控**：时段结束未签到自动标记爽约，累计爽约达到上限（默认 3 次）自动限制该用户预约 |

## 运行方式（二选一）

**方式一：本地直接打开**

双击 `index.html` 即可，无需安装任何软件。首次运行会自动写入示例数据（含待审核、已通过、爽约、受限用户等场景），方便体验完整流程。

**方式二：部署到 GitHub Pages（免费在线访问）**

1. 把本项目推送到 GitHub 仓库
2. 仓库页面 `Settings` → `Pages`
3. `Source` 选择 `main` 分支根目录，保存
4. 通过 `https://<你的用户名>.github.io/<仓库名>/` 访问

## 使用说明

1. **预约申请**：填写姓名 → 选实验室/日期/时段（已被占用的时段不可选）→ 填用途 → 提交，状态为"待审核"
2. **管理审核**：后台输入密码（默认 `admin123`）→ 对待审核申请点"通过"或"驳回"；通过前自动冲突检测，通过后系统生成 **6 位预约验证码**
3. **预约签到**：用户在"预约记录"中查看自己的验证码 → 在"预约签到"页输入验证码 → 系统校验是否处于预约时段内，时段内签到成功
4. **爽约管控**：预约时段结束仍未签到的，系统自动标记为"爽约"；同一姓名累计爽约达到上限（`data.js` 中 `MAX_NO_SHOW`，默认 3 次）后无法提交新预约
5. **解除限制**：管理员在后台"受限用户"板块查看受限用户与爽约记录，点击"解除限制"后该用户的爽约记录转为"已免除"，恢复预约权限
6. **记录查询**：搜索框输入姓名或用途关键词实时过滤，可与实验室、日期筛选组合使用

## 配置

编辑 [data.js](data.js)：

- `LABS`：实验室列表
- `TIME_SLOTS`：每天可预约时段
- `ADMIN_PASSWORD`：管理后台密码
- `MAX_NO_SHOW`：爽约次数上限，达到后自动限制预约

## 数据存储说明

数据保存在**浏览器 localStorage** 中（键名 `lab_reservations_v1`），不需要数据库。这意味着：

- 同一浏览器中数据持久保存，刷新、关闭重开都不会丢失
- 不同浏览器 / 不同电脑之间数据**不共享**（纯前端方案的天然限制）

如需多人跨设备真实使用，需要接入后端（如 Flask + SQLite、或 Supabase 等免费服务），前端页面和业务逻辑可直接复用。

**命令行上传**：

```bash
git init -b main
git add .

git remote add origin https://github.com/<你的用户名>/lab-reservation-system.git
git push -u origin main
```
