# 实验室预约管理系统

一个极简的实验室预约管理系统：**纯静态网页，零依赖、零安装、无需数据库**，双击 `index.html` 即可运行，也可直接部署到 GitHub Pages 在线使用。

## 功能

| 角色 | 功能 |
| --- | --- |
| 普通用户 | 选择实验室、日期、时段提交预约；查看预约记录与审核进度；取消自己的预约 |
| 管理员 | 登录管理后台（默认密码 `admin123`），审核申请：通过 / 驳回 |
| 系统 | **冲突检测**：同一实验室+日期+时段已被申请或占用时，禁止重复预约，并在下拉框中标记"已被占用" |

## 运行方式（二选一）

**方式一：本地直接打开**

双击 `index.html` 即可，无需安装任何软件。首次运行会自动写入 3 条示例数据（1 条已通过、2 条待审核），方便体验完整流程。

**方式二：部署到 GitHub Pages（免费在线访问）**

1. 把本项目推送到 GitHub 仓库
2. 仓库页面 `Settings` → `Pages`
3. `Source` 选择 `main` 分支根目录，保存
4. 通过 `https://<你的用户名>.github.io/<仓库名>/` 访问

## 使用说明

1. **预约申请**：填写姓名 → 选实验室/日期/时段（已被占用的时段不可选）→ 填用途 → 提交，状态为"待审核"
2. **管理后台**：输入密码（默认 `admin123`，在 `data.js` 中修改）→ 对待审核申请点"通过"或"驳回"；通过前会再次做冲突检测
3. **预约记录**：可按实验室、日期筛选，看到自己的预约状态和审核结果

## 配置

编辑 [data.js](data.js)：

- `LABS`：实验室列表
- `TIME_SLOTS`：每天可预约时段
- `ADMIN_PASSWORD`：管理后台密码

## 数据存储说明

数据保存在**浏览器 localStorage** 中（键名 `lab_reservations_v1`），不需要数据库。这意味着：

- 同一浏览器中数据持久保存，刷新、关闭重开都不会丢失
- 不同浏览器 / 不同电脑之间数据**不共享**（纯前端方案的天然限制）

如需多人跨设备真实使用，需要接入后端（如 Flask + SQLite、或 Supabase 等免费服务），前端页面和冲突检测逻辑可直接复用。
